# Product Requirements Document (PRD) — Automa Landing Page

## 1. Vision & Strategy
Automa is building the financial rails for autonomous software agents to transact on-chain via NEAR Protocol. The landing page serves as the entry point for AI developers, protocols, and builders to understand the value proposition in under 10 seconds.

## 2. Target Audience
1. **AI Agent Developers**: Engineers building autonomous agents who need programmable payment mechanisms.
2. **Web3 Developers**: Protocols and dapp creators seeking agent interoperability and commerce primitives.
3. **Ecosystem Partners**: Builders exploring agent-to-agent interaction models.

## 3. Guiding Principles & Guardrails
- **Honesty First**: Never fabricate metrics, user counts, token prices, or fictitious partners.
- **Clear Roadmap Framing**: Unshipped features are described as vision or exploration, never present-tense live products.
- **Refined Aesthetics**: Deep near-black surfaces, glowing violet ambient lighting, and sleek glassmorphism.

## 4. Key Metrics & Success Criteria
- Primary CTA click-through rate (`Explore Automa`)
- Secondary documentation engagement (`Read the Docs`)
- Zero dead links or empty anchors displayed to users
